These files are retained to show the team's development process. They are not production firmware
and should not be copied to the assembled vehicle without review.

| File | Status |
| --- | --- |
| `senses_bringup.py` | Earlier IMU-first sensor sequence; superseded by the ToF-first, IMU-last test |
| `multi_tof_poc.py` | Early five-ToF proof of concept |
| `VL53L1X_rng_vrfy.py` | Cannot run from this repository because its alternate `VL53L1X` driver is absent |
| `servo_teaching.py` | Contains an indentation syntax error; retained as a discarded prototype |
| `Multiple_LEDs.py` | Early GPIO exercise; conflicts with current GP13–GP15 assignments |
